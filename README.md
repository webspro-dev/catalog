# Bitrix Catalog Module

Модуль для 1С-Битрикс для управления каталогом товаров через административную панель.

Проект реализован на PHP с использованием Bitrix D7 API и ORM. Предусмотрены установка и удаление модуля, работа с собственной таблицей товаров, административный интерфейс и базовые операции управления данными.

## Возможности

- установка и удаление модуля через административную панель;
- создание собственной таблицы товаров;
- работа с данными через Bitrix D7 ORM;
- добавление товаров;
- редактирование товаров;
- удаление товаров;
- активация и деактивация товаров;
- административный список товаров;
- административная форма редактирования;
- настройки модуля;
- проверка прав доступа;
- защита административных операций;
- обработка ошибок ORM;
- русская локализация.

## ORM-модель

Для работы с товарами используется собственная ORM-сущность `ProductTable`.

Основные поля:

| Поле        | Тип      | Описание             |
| ----------- | -------- | -------------------- |
| ID          | Integer  | Идентификатор товара |
| NAME        | String   | Название товара      |
| CODE        | String   | Символьный код       |
| PRICE       | Float    | Цена                 |
| ACTIVE      | Boolean  | Активность           |
| DATE_CREATE | DateTime | Дата создания        |
| DATE_UPDATE | DateTime | Дата изменения       |

Пример выборки данных:

```php
use Websbro\DemoCatalog\Model\ProductTable;

$result = ProductTable::getList([
    'select' => [
        'ID',
        'NAME',
        'PRICE',
        'ACTIVE',
    ],
    'order' => [
        'ID' => 'DESC',
    ],
]);

while ($product = $result->fetch()) {
    // Обработка товара
}
```

## Добавление товара

```php
ProductTable::add([
    'NAME' => 'Product name',
    'CODE' => 'product-name',
    'PRICE' => 19990,
    'ACTIVE' => 'Y',
]);
```

## Обновление товара

```php
ProductTable::update($productId, [
    'PRICE' => 17990,
    'ACTIVE' => 'Y',
]);
```

## Удаление товара

```php
ProductTable::delete($productId);
```

## Установка

Скопировать каталог модуля:

```text
websbro.democatalog
```

в:

```text
/local/modules/
```

В результате структура должна выглядеть следующим образом:

```text
/local/modules/websbro.democatalog/
```

После копирования открыть административную панель 1С-Битрикс:

```text
Настройки
→ Marketplace
→ Установленные решения
```

Найти модуль **«Каталог товаров»** и выполнить установку.

После установки в административной панели появится раздел для работы с товарами.

## Работа с каталогом

После установки доступны операции:

1. создание товара;
2. редактирование;
3. удаление;
4. активация;
5. деактивация;
6. просмотр списка товаров;
7. изменение настроек модуля.

## Удаление

Модуль можно удалить стандартными средствами 1С-Битрикс через:

```text
Настройки
→ Marketplace
→ Установленные решения
```

При удалении модуля его таблица данных удаляется из базы данных.

Перед удалением рабочего модуля рекомендуется сделать резервную копию базы данных.
